# Qt 串口调试助手需求规格说明书

**参考对象**：SSCOM 5.13.1  
**版本**：V1.0  
**日期**：2026-10-12  
**技术栈**：Qt 6.5 LTS + Qt Widgets + Qt SerialPort + C++17 + CMake  
**目标平台**：Windows 10/11 优先，后续可跨平台  
**一致性目标**：功能、布局、操作流程、默认值尽量与 SSCOM 5.13.1 保持一致，满足“习惯延续”需求。

> 说明：本文档用于指导独立开发，不以反编译、复制原软件代码或资源为前提。可参考其公开功能与操作习惯，但名称、图标、界面素材需自行设计。

---

## 1. 项目概述

### 1.1 背景

用户长期使用 SSCOM 5.13.1 进行串口调试，希望用 Qt 开发一个功能与操作习惯高度一致的替代工具。

### 1.2 目标

- 实现串口调试核心功能：串口配置、数据收发、HEX/ASCII 显示、多字符串发送、自动发送、数据保存等。
- 主界面布局、控件位置、操作流程尽量贴近 SSCOM 5.13.1。
- 保证高波特率下稳定、不丢数据、UI 不卡顿。
- 配置可持久化，重启后恢复上次使用状态。

### 1.3 范围

**包含**：串口管理、接收区、发送区、多字符串发送、自动发送、状态栏、配置保存、日志保存、辅助工具。  
**不包含**：反编译原软件、复制原软件图标/名称、网络通信、Modbus 协议解析等 SSCOM 本身不具备的扩展功能。

---

## 2. 用户与使用场景

| 场景       | 描述                                   |
| ---------- | -------------------------------------- |
| 嵌入式调试 | 连接开发板，查看串口日志，发送 AT 指令 |
| 设备测试   | 循环发送固定指令，观察设备返回         |
| 协议分析   | HEX 模式收发，校验数据帧               |
| 长时间抓取 | 自动保存接收数据，暂停/继续显示        |
| 多指令切换 | 使用多字符串列表快速发送不同指令       |

---

## 3. 总体设计原则

1. **功能一致**：SSCOM 5.13.1 有的核心功能，本软件均需具备。
2. **布局一致**：左侧串口配置与多字符串发送，右侧大接收区，下方发送输入区。
3. **操作一致**：按钮名称、勾选项、默认值、快捷键尽量相同。
4. **独立实现**：代码、图标、名称自行设计，避免版权风险。
5. **稳定优先**：高波特率、热插拔、长时间运行不崩溃。

## 4. 功能需求

### FR-01 串口管理（P0）

| 编号    | 需求          | 说明                                              |
| ------- | ------------- | ------------------------------------------------- |
| FR-01-1 | 串口枚举      | 启动时自动列出可用串口，如 COM1、COM2             |
| FR-01-2 | 刷新串口      | 支持手动刷新，识别热插拔                          |
| FR-01-3 | 打开/关闭串口 | 按钮状态互斥，打开后显示“关闭串口”                |
| FR-01-4 | 参数配置      | 串口号、波特率、数据位、校验位、停止位、流控      |
| FR-01-5 | 默认值        | 建议与 SSCOM 一致：COM1、9600、8、None、1、无流控 |
| FR-01-6 | DTR/RTS       | 提供 DTR、RTS 复选框控制                          |
| FR-01-7 | 异常处理      | 串口被占用、拔出、打开失败时弹窗提示，不崩溃      |

### FR-02 接收区（P0）

| 编号     | 需求         | 说明                           |
| -------- | ------------ | ------------------------------ |
| FR-02-1  | ASCII 显示   | 按文本显示接收数据             |
| FR-02-2  | HEX 显示     | 每字节两位十六进制，空格分隔   |
| FR-02-3  | 暂停显示     | 暂停后数据继续接收但不刷新 UI  |
| FR-02-4  | 清空显示     | 一键清空接收区                 |
| FR-02-5  | 保存数据     | 将接收区内容保存为文件         |
| FR-02-6  | 时间戳       | 可选显示 `[HH:mm:ss.zzz]`      |
| FR-02-7  | 自动换行     | 可选自动换行                   |
| FR-02-8  | 显示发送数据 | 勾选后，发送内容也显示在接收区 |
| FR-02-9  | 字体设置     | 可调整接收区字体、字号         |
| FR-02-10 | 右键菜单     | 复制、清空、保存、暂停         |
| FR-02-11 | 接收计数     | 状态栏实时显示接收字节数       |

### FR-03 发送区（P0）

| 编号    | 需求     | 说明                                 |
| ------- | -------- | ------------------------------------ |
| FR-03-1 | 文本发送 | 输入框内容按 ASCII 发送              |
| FR-03-2 | HEX 发送 | 输入十六进制字符串，如 `01 02 0D 0A` |
| FR-03-3 | 发送新行 | 可选自动追加 `\r\n`                  |
| FR-03-4 | 定时发送 | 设置间隔毫秒数，循环发送输入框内容   |
| FR-03-5 | 停止发送 | 可随时停止定时发送                   |
| FR-03-6 | 发送文件 | 选择文件，按字节发送                 |
| FR-03-7 | 发送计数 | 状态栏实时显示发送字节数             |

### FR-04 多字符串发送（P0，核心特性）

| 编号    | 需求       | 说明                                         |
| ------- | ---------- | -------------------------------------------- |
| FR-04-1 | 最多 32 条 | 与 SSCOM 一致                                |
| FR-04-2 | 每条独立   | 包含：使能勾选、HEX/文本模式、内容、发送按钮 |
| FR-04-3 | 单条发送   | 点击某行“发送”按钮，立即发送该条             |
| FR-04-4 | 循环发送   | 勾选循环后，按设定间隔依次发送使能项         |
| FR-04-5 | 间隔设置   | 毫秒级，建议范围 1~60000                     |
| FR-04-6 | 快捷编辑   | 内容可直接编辑，支持回车确认                 |
| FR-04-7 | 配置保存   | 发送列表随软件关闭自动保存                   |

### FR-05 自动发送（P1）

- 可对当前发送区内容设置自动发送。
- 间隔可调，支持 1ms 起。
- 自动发送时按钮状态切换为“停止”。

### FR-06 状态栏（P0）

- 显示串口状态：已打开/已关闭。
- 显示当前参数：COM 口、波特率、数据位、校验位、停止位。
- 显示接收字节数、发送字节数。
- 显示清空计数按钮或右键菜单。

### FR-07 配置持久化（P0）

使用 `QSettings` 保存：

- 窗口位置、大小。
- 上次串口参数。
- 接收区显示选项。
- 发送区内容。
- 多字符串列表全部内容。
- 自动发送间隔。

### FR-08 菜单与快捷键（P1）

| 菜单 | 功能                                             |
| ---- | ------------------------------------------------ |
| 文件 | 保存接收数据、退出                               |
| 操作 | 打开串口、关闭串口、刷新串口、清空接收、清空发送 |
| 帮助 | 关于、使用说明                                   |

建议快捷键：

- `Ctrl+O`：打开串口
- `Ctrl+D`：关闭串口
- `Ctrl+L`：清空接收区
- `Ctrl+S`：保存接收数据

### FR-09 辅助工具（P2）

- 校验和计算：SUM、XOR、CRC16。
- 字符串转 HEX、HEX 转字符串。
- 若原版有“扩展”按钮，则提供类似入口。

### 5.2 控件要求

- 使用 `QComboBox`、`QCheckBox`、`QPushButton`、`QPlainTextEdit`、`QTableWidget`、`QStatusBar`。
- 接收区使用 `QPlainTextEdit`，设置为只读，支持大文本。
- 多字符串列表使用 `QTableWidget`，列：使能、模式、内容、发送。
- 窗口可调整大小，各区域按比例伸缩。
- 字体默认等宽字体，如 Consolas。

### 5.3 交互细节

- 打开串口后，串口配置控件可禁用，防止误改。
- 接收区滚动条自动到底部，除非用户手动上滚。
- HEX 输入非法时，发送按钮置灰或弹窗提示。
- 关闭窗口时自动保存配置。

## 7. 技术架构

### 7.1 分层

- **UI 层**：MainWindow、接收区、发送区、多字符串表格。
- **业务层**：SerialPortManager、SendQueueManager、DataFormatter。
- **通信层**：QSerialPort、QSerialPortInfo。
- **持久层**：QSettings、QFile。

### 7.2 核心类

| 类                  | 职责                             |
| ------------------- | -------------------------------- |
| `MainWindow`        | 主界面、菜单、状态栏、信号槽连接 |
| `SerialPortManager` | 枚举、打开、关闭、参数配置、读写 |
| `DataFormatter`     | ASCII/HEX 转换、时间戳、换行     |
| `SendQueueManager`  | 多字符串循环发送、定时发送       |
| `ConfigManager`     | QSettings 读写配置               |
| `LogWriter`         | 接收数据保存到文件               |

### 7.3 线程模型

- `SerialPortManager` 运行在独立 `QThread`。
- 接收数据通过 `readyRead` 信号触发，读入缓冲区。
- UI 定时器批量取出缓冲区数据并刷新显示。
- 发送数据通过信号槽投递到串口线程。

### 7.4 数据模型

```cpp
struct SerialConfig {
    QString portName;
    qint32 baudRate;
    QSerialPort::DataBits dataBits;
    QSerialPort::Parity parity;
    QSerialPort::StopBits stopBits;
    QSerialPort::FlowControl flowControl;
    bool dtr;
    bool rts;
};

struct SendItem {
    bool enabled;
    bool hexMode;
    QString content;
    bool loop;
};
```

## 8. 验收标准

1. 能正确枚举本机串口，插拔后刷新可见。
2. 能打开/关闭串口，参数设置生效。
3. 115200 波特率连续收发 10 万字节，无丢失，UI 不卡死。
4. 接收区 ASCII/HEX 切换显示正确。
5. 时间戳、暂停、清空、保存功能正常。
6. 发送区支持文本、HEX、新行、定时发送。
7. 多字符串支持 32 条，可独立编辑、HEX/文本、单条发送、循环发送。
8. 关闭软件再打开，串口参数、发送列表、窗口大小恢复。
9. 拔掉串口后程序不崩溃，状态栏更新为“已关闭”。
10. 保存的接收数据文件内容与接收区一致。

## 10. 风险与限制

1. **功能细节差异**：SSCOM 未开源，部分隐藏功能需通过使用习惯确认。
2. **像素级一致困难**：Qt 控件与原 Windows 控件外观存在差异，建议追求“操作一致”而非“像素一致”。
3. **串口驱动差异**：不同 USB 转串口芯片行为略有不同，需多设备测试。
4. **法律风险**：不得使用原软件名称、图标、反编译代码。
